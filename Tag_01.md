## Was ich heute gelernt habe:
### Merkmalstypen: 
Häufbare Merkmale können mehrfach vorkommen, beispielsweise Hobbys. Diskrete Merkmale sind abzählbar, wie die Anzahl Teilnehmer. Stetige Merkmale werden gemessen, beispielsweise das Gewicht.

Hier ist meine Tabelle von den zugeordneten Wörtern zu den 3 Merkmalstypen:
| Häufbar          | Diskret          | Stetig        |
| ---------------- | ---------------- | ------------- |
| Hobby            | Teilnehmeranzahl | Wasserpegel   |
| Berufsausbildung | Haarfarbe        | Gewicht       |
|                  | Geschlecht       | Zeitintervall |
|                  |                  | Strecke       |

## Skalentypen: 
Die Nominalskala unterscheidet Kategorien ohne Reihenfolge, zum Beispiel Augenfarben. Die Ordinalskala ermöglicht eine Rangfolge, beispielsweise bei der Zufriedenheit. Bei der Kardinalskala sind auch die Abstände zwischen Zahlenwerten sinnvoll messbar, wie bei einer Streckenlänge.

Hier ist meine Tabelle von den zugeordneten Wörtern zu den 3 Skalentypen:
| Nominalskala | Ordinalskala | Kardinalskala |
|---|---|---|
| Geschlecht | Zufriedenheit (1–5) | Zeitdauer |
| Kontonummer | Militär-Dienstrang | Streckenlänge |
| Haarfarbe | Präferenzrangfolge | Wassertiefe |
| Telefonnummer | | |
| Geschmacksrichtung | | |
